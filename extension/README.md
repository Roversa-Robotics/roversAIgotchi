# PetBot Extension

The PetBot extension adds custom MakeCode blocks for the RoversAIgotchi project. It provides blocks for pet behaviors, wellbeing tracking, and game mechanics.

## Repository

The extension source code lives in its own repository (required by MakeCode):

**[extension-roversaigotchi](https://github.com/marianaarboleda/extension-roversaigotchi)**

## How to Add the Extension to a MakeCode Project

1. Open your project in [MakeCode](https://makecode.microbit.org)
2. Click the **gear icon** (⚙️) → **Extensions**
3. Paste the extension repository URL:
   ```
   https://github.com/marianaarboleda/extension-roversaigotchi
   ```
4. Click the extension to add it to your project

## What It Provides

- **Behaviors** — blocks for defining how your PetBot reacts (happy, sad, hungry, etc.)
- **Wellbeing** — blocks for tracking your PetBot's wellbeing stats
- **Game** — blocks for game mechanics and interactions
