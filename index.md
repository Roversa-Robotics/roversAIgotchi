# Roversa PetBot Hub
{: .fs-9 }

<img src="{{ '/assets/roversa.png' | relative_url }}" alt="Roversa PetBot" height="120" />

Central hub for everything related to the **Roversa PetBot** — a micro:bit-powered virtual pet built with [Roversa](https://www.roversa.com/home.html).
{: .fs-6 .fw-300 }

Each MakeCode project lives in its own repository (as MakeCode requires), and this hub keeps them organized in one place — the extension, starter code, and classroom challenges.
