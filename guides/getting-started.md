# Getting Started

Everything you need to set up and start using the RoversAIgotchi PetBot projects.

## What You Need

- A [Roversa](https://www.roversa.com/home.html) robot and USB cable
- A computer with a web browser
- Access to [makecode.microbit.org](https://makecode.microbit.org)

## Opening a Project

Each project has a **Share Link** that opens it directly in MakeCode:

1. Go to the [Projects & Challenges](../projects/README.md) page
2. Click the **Open in MakeCode** link for the project you want
3. The project opens in the MakeCode editor, ready to use

## Flashing to Your micro:bit

1. Connect your Roversa to your computer via USB
2. In MakeCode, click the **Download** button
3. Copy the `.hex` file to the `MICROBIT` drive that appears
4. Your Roversa will restart with the new code

## Adding the PetBot Extension Manually

If you're starting a project from scratch and need to add the extension:

1. In MakeCode, click the **gear icon** (⚙️) → **Extensions**
2. Paste this URL:
   ```
   https://github.com/marianaarboleda/extension-roversaigotchi
   ```
3. Click the extension to add it

See the [Extension docs](../extension/README.md) for more details on what blocks are available.
