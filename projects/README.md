## Adding a New Project

To add a new project to the hub:

1. Create the MakeCode project and get its share link
2. Create a new folder: `projects/NN-project-name/`
3. Add a `README.md` with the project description, share link, and learning goals
4. Update this table and the root [README.md](../README.md)
